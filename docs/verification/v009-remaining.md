## TLS handshake isolation fix

Code inspection after the external handshake failures found accepted sockets
performed their TLS handshake in the manager accept thread. A deterministic
loopback regression held one raw peer before TLS negotiation and demonstrated
that another authenticated worker poll failed with a handshake timeout. Moving
handshakes into their individual request threads makes that regression pass;
accepted sockets retain the ten-second timeout, TLS validation and handler join
on shutdown. This is a reproduced blocking path, not proof it was the sole
cause of the external link's deadline failure. Untrusted-certificate rejection
still passes. `make check` then passed all 320 tests, compileall and whitespace
checks in 73.596 seconds (`/tmp/v009-tls-pool-check.log`).
